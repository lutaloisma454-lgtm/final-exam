# Question 4 — Complete Java Interfaces Example

## Project files
- `src/X.java` — Interface X
- `src/Y.java` — Interface Y
- `src/A.java` — Both interfaces and calling the required methods and constants

## How to run the system.
mkdir -p out
javac -d out src/X.java src/Y.java src/A.java
java -cp out A

## Expected output
I am from X
I am from Y
W in X = 5
W in Y = 10
Message: Welcome to Java interfaces
Square of 5 = 25
